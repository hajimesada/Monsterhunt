# おうちモンスターハント Ver.1

GitHub Pagesで動かせる、子供向けの疑似ARモンスター探索PWAです。

## 入っている機能
- 背面カメラ表示
- スマホの向きセンサーを使った360°探索
- センサー非対応時の左右ボタン探索
- ★1〜★5の難易度
- 高難易度ほど複数回見つけないと捕獲戦に進まない
- モンスターボールのスワイプ投球
- 難易度別の捕獲率
- 図鑑 / 捕獲数の端末内保存
- Service WorkerによるPWAキャッシュ
- iPhone / Androidホーム画面追加向け設定
- カメラ映像の録画・アップロードなし

## GitHub Pages公開
1. このフォルダの中身をGitHubのリポジトリ直下へアップロード
2. GitHub → Settings → Pages
3. Build and deployment → Deploy from a branch
4. Branch: main / /(root) → Save
5. 表示された `https://ユーザー名.github.io/リポジトリ名/` をスマホで開く

## iPhone / iPad
SafariでURLを開き、共有ボタン →「ホーム画面に追加」。

初回の「探索スタート」でカメラと端末の向きへのアクセスを許可してください。

## Android
Chrome等でURLを開き、メニュー →「ホーム画面に追加」または「インストール」。

## 注意
このVer.1はGPSやARKitで実距離10mを測る方式ではなく、端末の向きから「家の中を探している感覚」を作る疑似ARです。
モンスター画像は著作権キャラクターではなく、現状は絵文字プレースホルダーです。
